# FDE 学习台 · 12 周从零到能面试

> 一个**离线可用的单文件学习 App**：双击打开，不需要服务器，不需要联网，进度存在本机浏览器。
> 内容从「电脑到底在干什么」这种扫盲开始，一直到能去面试 FDE（Forward Deployed Engineer）。

---

## 这是什么

很多「转行教程」的问题是从第一行就直接教你写代码，跳过了一个事实：

> **你连「程序是什么」都还没搞清，就开始学语法，注定学不下去。**

这个 App 的结构是：

| 阶段 | 周 | 干什么 |
|---|---|---|
| **扫盲 + 能写** | W1 | 程序是什么 → 变量/条件/循环 → 第一个能跑的文件 |
| | W2 | 列表/字典/函数/参数 → 50 行小工具 |
| | W3 | 异常、测试、调试、重构 → 从「能跑」到「改得动」 |
| | W4 | 做出第一个真项目：**字幕质检工具** |
| **能交付** | **W5** | **评测（最重要）**：证明它有用，不只是能跑 |
| | W6 | 配置、日志、多格式、失败不崩 |
| **能上线** | W7 | 加 AI（翻译 + 术语校验 + 成本核算） |
| | W8 | 部署上线 + 监控 |
| | W9 | 交付四件套 + 3 分钟 demo |
| **能面试** | W10 | 读透一个 1.1 万行的陌生系统 |
| | W11 | 3 个案例 + 简历 + STAR 故事 |
| | W12 | 作品集 + 投递 |

**前 4 周拆到 28 天**，每天有：学什么 / 概念 / 动手任务 / 参考代码 / 验收清单。
**第 5–12 周**给每周任务清单（每天一条）。

## 怎么打开

### 最快

双击 `FDE学习App.html`。就这样。

### 如果 macOS 提示「无法验证开发者」

右键 → 打开 → 再点「打开」。只需一次。

### 用启动脚本（macOS / Linux）

```bash
./start.sh
```

### 在线阅读（部署到 GitHub Pages 之后）

如果仓库开了 GitHub Pages，可以直接访问：
`https://<你的用户名>.github.io/<仓库名>/FDE学习App.html`

工作流已经配好（`.github/workflows/pages.yml`），push 到 main 就自动部署。

## 三条使用原则

1. **每天只做一天**：打开首页 → 点「打开这一天的课」→ 照着敲，不要往下翻。
2. **前 9 周关掉 AI 写代码**：你缺的不是「指挥 AI 写对」，是「AI 写错时你能看出来」。
3. **卡 30 分钟就跳过**：记下来，周末集中解决。

## 练习代码怎么跑

```bash
cd 练习代码/python/week2
python3 batch.py ../../练习数据      # 批量统计
python3 -m unittest test_analyze -v    # 跑测试（零安装，用自带 unittest）
python3 bug1.py                        # 看除零报错
python3 bug2.py                        # 判断「这是 bug 吗」
python3 bug3.py                        # 闭包陷阱：输出 2 2 2
python3 messy.py ../../练习数据/sample.txt # 40 行「一坨」，练重构
```

> **不需要 pip install 任何东西。** 全部用 Python 3.9+ 自带的能力。

## 改内容

课程内容在 `构建/build_app.py` 顶部的三个变量：`WEEKS`（课程）、`CONCEPTS`（概念）、`QUIZ`（测验）。

改完：

```bash
python3 构建/build_app.py
```

会重新生成 `FDE学习App.html`。**进度不会丢**（存在浏览器里，和文件无关）。

## 关于「能不能入职」

这个仓库不承诺「12 周拿 offer」。它承诺的是：

> **12 周后，你有一个能演示的作品、能讲清取舍、能扛住技术追问、知道自己下一步该补什么。**

真实路径是：学完 → 有作品 → 有人愿意见你 → 面 3–5 家 → 拿 1 个 offer。
**offer 通常在第 4–6 个月，不在第 12 周。**
