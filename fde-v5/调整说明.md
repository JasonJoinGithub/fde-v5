## v5 第一件事：修好了「每次打开都从零开始」

**根因（大白话）：** 不是你的进度被删了，是浏览器根本没把它存到同一个地方。
你以前是直接双击 `FDE学习App.html` 打开的，浏览器地址是 `file://`。这种打开方式下，Safari 存不住 localStorage；Chrome 则按文件路径给每个副本各存一份——打开 v3 的副本、v4 的副本、重新下载的副本，进度各算各的，等于每次从零开始。

**修法：**

1. **改打开方式，不改进度本身。** `start.sh` 和新加的 `打开学习台.command` 现在先起一个本地服务（`http://127.0.0.1:8000`），再用浏览器打开。这个地址是一个固定来源，不管 HTML 是哪个版本，只要从同一个服务打开，进度都存在同一个地方，跨版本也能留住。服务只在你自己电脑上跑，不联网、不上传。停止办法：回到终端窗口按 `Ctrl+C`。
2. **KEY 没变，还是 `fde_app_v1`。** 所以用本地服务打开 v5 时，v4 在同一个来源下存过的进度能直接迁移过来。
3. **加了存储健康检查。** 每次打开，App 先试写、试读一个测试 key；写不进去或读不回来，就在首页和「我的进度」里亮一条红色警告：「当前打开方式存不住进度（file://)，请用本地服务方式打开，或每次学完导出进度文件」。
4. **首页加了一张显眼的「进度」卡**：上次打开时间、已完成天数、一个大大的「导出进度文件」按钮和「导入进度文件」按钮。页脚的导出/导入按钮还在。
5. **没找到进度时有提示。** 如果打开时一点进度都没有，会在首页出现一条提示：「没找到学习进度？如果你以前学过，点这里导入进度文件」。
6. **每次保存都记时间。** `save()` 现在同时写 `lastOpened`（ISO 时间戳），首页和「我的进度」都显示上次打开时间。

**以后怎么打开（只记住这一句）：双击「打开学习台.command」，别直接双击 HTML。** 直接双击 HTML 现在被标成「不推荐，会丢进度」。实在要用，每次学完必须导出进度文件备份。
