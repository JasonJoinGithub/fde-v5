# 第 0 天：装环境（60–90 分钟）

> **今天不学编程，只把"能干活的工作台"搭起来。**
> 装完之后你能：打开终端、写一个 .py 文件、运行它、看懂报错。

---

## 0.1 先建好你的代码文件夹

打开"终端"（Terminal）——在启动台搜 "终端" 或 "Terminal"。

复制粘贴这一行，回车：

```bash
mkdir -p ~/fde-code/week1 && cd ~/fde-code && pwd
```

**你应该看到**：`~/fde-code`

> 以后所有练习代码都放这个文件夹里。**不要放桌面，不要放下载目录。**

---

## 0.2 装 VS Code（代码编辑器）

你现在没有代码编辑器。装一个。

1. 浏览器打开：**https://code.visualstudio.com/**
2. 点中间的大按钮 **Download for macOS**
3. 下载完是一个 zip，解压后把 **Visual Studio Code** 拖进「应用程序」文件夹
4. 打开它，如果提示"无法验证开发者"→ 右键点图标 → 选「打开」→ 再点「打开」

**装完做一件事**：VS Code 里按 `Cmd + Shift + P`，输入 `shell command`，选 **"Install 'code' command in PATH"**。
这样以后在终端里输入 `code .` 就能打开当前文件夹。

---

## 0.3 验证 Python 能跑

终端里执行：

```bash
python3 -V
```

**你应该看到**：`Python 3.9.6`（或更高的 3.9.x / 3.12.x）

> 看到版本号就说明 Python 装好了。**Mac 自带，不用装新的。**

再试一次"直接运行代码"：

```bash
python3 -c "print('hello')"
```

**你应该看到**：`hello`

> 如果这里报错，先停下来，把报错原文贴给我。

---

## 0.4 写你的第一个文件

终端里执行（一行一行来）：

```bash
cd ~/fde-code/week1
code . 
```

VS Code 会打开这个文件夹。在左边空白处：

1. 点「新建文件」图标（或 `Cmd + N`）
2. 文件名输入：`hello.py`
3. 敲进去：

```python
print("我今天开始学 FDE")
print("这是我的第一个 Python 文件")
```

4. `Cmd + S` 保存
5. 回终端，执行：

```bash
python3 hello.py
```

**你应该看到两行字。**

> ⚠️ **注意**：`hello.py` 必须保存在 `~/fde-code/week1/` 里。放在别的地方会报"找不到文件"。

## 0.5 学会看报错（今天最重要的一件事）

**故意制造一个错误**，看看它长什么样。

把 `hello.py` 改成：

```python
print("我今天开始学 FDE"
```

（故意少一个右括号）

保存，运行 `python3 hello.py`。

**你会看到类似这样的一大段**：

```
  File "~/fde-code/week1/hello.py", line 1
    print("我今天开始学 FDE"
         ^
SyntaxError: '(' was never closed
```

**学会读它的三个部分**（这是你以后每天都要用的技能）：

| 部分 | 意思 | 例子 |
|---|---|---|
| `File "...", line 1` | **哪个文件的第几行** | `hello.py` 第 1 行 |
| `^` 指向的位置 | **大概错在哪** | 指向 `print(` 的括号 |
| `SyntaxError: ...` | **错误的类型和原因** | 括号没闭合 |

**修好它**，再加一个右括号，重新运行，确认能跑。

> **记住这句话**：报错不是失败，是 Python 在告诉你哪里不对。**看报错的第一行和最后一行，中间可以先不看。**

## 0.6 装一个能帮你检查代码的工具（可选，但推荐）

```bash
python3 -m pip install --user black
```

如果报错说权限不够，换成：

```bash
python3 -m pip install --user --break-system-packages black
```

装完后，以后可以对任何文件执行：

```bash
python3 -m black hello.py
```

它会自动把代码排版整齐。**今天不用管它，知道有这个东西就行。**

## 0.9 常见问题

**Q：终端说 `command not found: python3`**
A：说明系统没装 Xcode 命令行工具。执行 `xcode-select --install`，装完再试。

**Q：`code .` 没反应**
A：VS Code 里没装 shell command。回 0.2 最后一步。

**Q：中文显示成乱码**
A：终端设置问题，暂时不影响。如果 `print("中文")` 输出乱码，告诉我。

**Q：我打字很慢**
A：正常。**前两周你只需要打 20–60 行代码，慢也没关系。** 打字不是这门课的重点。
