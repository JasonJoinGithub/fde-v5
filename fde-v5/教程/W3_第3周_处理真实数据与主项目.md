### 亲手敲 `w3/read_json.py`

```python
# read_json.py
# 作用：读一个 JSON 文件，打印每个项目的名字和星数

import json


def load(path):
    with open(path, "r", encoding="utf-8") as f:
        return json.load(f)


def main():
    repos = load("repos.json")
    print("一共", len(repos), "个项目")
    for r in repos:
        print(r["name"], r["stars"])


if __name__ == "__main__":
    main()
```

运行：`python3 read_json.py`

### 必须理解的点

**1. `json.load(f)` 把 JSON 变成 Python 的列表/字典**
JSON 的 `{}` → Python 的 `dict`
JSON 的 `[]` → Python 的 `list`
JSON 的 `null` → Python 的 `None`

**2. `r["name"]` 和 `r.get("name")` 的区别**

| 写法 | 键不存在时 |
|---|---|
| `r["name"]` | **报错 KeyError** |
| `r.get("name")` | 返回 `None`（可以给默认值 `r.get("name", "未知")`） |

**处理真实数据时，几乎都用 `.get()`**——因为字段经常缺。

### 动手改（必做）

1. 给每个项目加一个 `"stars"` 不存在的，看 `r["stars"]` 怎么崩，改成 `.get("stars", 0)`
2. 过滤掉 `license` 为 `None` 的项目，只打印有许可证的
3. 按 stars 从高到低排序后打印

### 验收

- [ ] 能读出 3 个项目
- [ ] 能解释 `.get()` 为什么比 `[]` 安全

## Day 16 · CSV：最常见的"脏数据"

### 学一个概念：CSV 的秘密是"逗号"和"引号"

CSV 看着简单，但它有坑：**字段里如果有逗号，必须用引号包起来**。

### 亲手造一份"脏"CSV

新建 `w3/projects.csv`：

```csv
name,owner,stars,license
subtitle-qc,liujiawei,120,MIT
old-tool,unknown,8,
"tool, with comma",someone,45,GPL-3.0
video-helper,,33,Apache-2.0
```

注意第 3 行的引号，第 4 行 owner 是空的，第 2 行 license 是空的。

### 亲手敲 `w3/read_csv.py`

```python
# read_csv.py
# 作用：读 CSV，跳过没有 owner 的行，按 stars 排序

import csv


def load(path):
    rows = []
    with open(path, "r", encoding="utf-8", newline="") as f:
        reader = csv.DictReader(f)
        for row in reader:
            rows.append(row)
    return rows


def main():
    rows = load("projects.csv")
    print("原始行数：", len(rows))

    clean = []
    for r in rows:
        if not r.get("owner"):
            continue
        if not r.get("stars"):
            continue
        r["stars"] = int(r["stars"])
        clean.append(r)

    clean.sort(key=lambda r: r["stars"], reverse=True)

    for r in clean:
        print(r["name"], "|", r["owner"], "|", r["stars"])


if __name__ == "__main__":
    main()
```

### 必须理解的点

**1. `csv.DictReader` 自动用第一行当键名**
每行变成一个字典，非常方便。

**2. `newline=""` 为什么必须加**
不加，Windows 换行符会出问题。**这是 CSV 的标准写法，记住就行。**

**3. `int(r["stars"])` 为什么要转**
CSV 读出来**全是字符串**。`"120"` 和 `120` 不能比较大小。

> **这是新手最常踩的坑**：以为读出来是数字，其实全是字符串。

### 动手改（必做）

1. 打印"被跳过了几行"，并说明每行为什么被跳过
2. 支持 name 里带逗号的那一行（你会发现 `DictReader` 已经自动处理了——这是它的价值）
3. 如果 `int()` 转换失败（比如星数是 `"N/A"`），会发生什么？加个 `try` 接住

### 验收

- [ ] 能读出并清洗数据
- [ ] 能说清"为什么全是字符串"
- [ ] 能处理转换失败

### 今天只做一件事：把 SRT 解析出来

新建 `subtitle_qc/parser.py`：

```python
# parser.py
# 作用：把 SRT 文件解析成结构化的条目列表


def parse_time(text):
    """把 '00:00:01,000' 转成毫秒数。"""
    hms, ms = text.split(",")
    h, m, s = hms.split(":")
    return int(h) * 3600000 + int(m) * 60000 + int(s) * 1000 + int(ms)


def parse_srt(path):
    """解析 SRT 文件，返回条目列表。"""
    with open(path, "r", encoding="utf-8") as f:
        content = f.read()

    blocks = content.strip().split("\n\n")
    items = []

    for block in blocks:
        lines = block.strip().split("\n")
        if len(lines) < 3:
            continue

        index = lines[0].strip()
        time_line = lines[1].strip()
        text = " ".join(line.strip() for line in lines[2:])

        if "-->" not in time_line:
            continue

        start_str, end_str = time_line.split("-->")
        start = parse_time(start_str.strip())
        end = parse_time(end_str.strip())

        items.append({
            "index": index,
            "start": start,
            "end": end,
            "duration": end - start,
            "text": text,
        })

    return items
```

## Day 18 · 主项目：写质检规则

### 学一个概念：规则 = 一个判断函数 + 一个理由

每一条质检规则，都是"**在什么情况下，这算问题**"。

### 亲手敲 `subtitle_qc/rules.py`

```python
# rules.py
# 作用：字幕质检规则。每条规则返回一个问题（或 None）


def check_overlap(items):
    """时间轴重叠：后一条开始时间 < 前一条结束时间。"""
    problems = []
    for i in range(1, len(items)):
        prev = items[i - 1]
        cur = items[i]
        if cur["start"] < prev["end"]:
            problems.append({
                "type": "overlap",
                "index": cur["index"],
                "detail": "和第 %s 条重叠了 %d 毫秒" % (prev["index"], prev["end"] - cur["start"]),
                "level": "high",
            })
    return problems


def check_too_short(items, min_ms=800):
    """单条时长过短。"""
    problems = []
    for it in items:
        if it["duration"] < min_ms:
            problems.append({
                "type": "too_short",
                "index": it["index"],
                "detail": "只有 %d 毫秒，观众读不完" % it["duration"],
                "level": "medium",
            })
    return problems


def check_line_length(items, max_chars=20):
    """单行过长。"""
    problems = []
    for it in items:
        if len(it["text"]) > max_chars:
            problems.append({
                "type": "too_long",
                "index": it["index"],
                "detail": "有 %d 个字，超过 %d" % (len(it["text"]), max_chars),
                "level": "medium",
            })
    return problems


def check_cps(items, max_cps=20):
    """阅读速度（字/秒）超标。"""
    problems = []
    for it in items:
        seconds = it["duration"] / 1000.0
        if seconds <= 0:
            continue
        cps = len(it["text"]) / seconds
        if cps > max_cps:
            problems.append({
                "type": "too_fast",
                "index": it["index"],
                "detail": "每秒 %.1f 个字，超过 %d" % (cps, max_cps),
                "level": "high",
            })
    return problems


def check_empty(items):
    """空文本。"""
    problems = []
    for it in items:
        if it["text"].strip() == "":
            problems.append({
                "type": "empty",
                "index": it["index"],
                "detail": "文本是空的",
                "level": "high",
            })
    return problems


ALL_CHECKS = [
    check_overlap,
    check_too_short,
    check_line_length,
    check_cps,
    check_empty,
]


def run_all(items):
    """跑所有规则，返回全部问题。"""
    problems = []
    for check in ALL_CHECKS:
        problems.extend(check(items))
    return problems
```

### 关键理解

**1. 每条规则是独立的函数**
好处：可以单独测试、可以单独开关、可以加新规则而不动老规则。

**2. `level`（严重程度）为什么要标**
交付给客户时，客户最关心"哪些必须改"（high）和"哪些建议改"（medium）。

**3. 阈值为什么要能传参**
`min_ms=800` 这种写法，让调用方可以改标准。**不同客户标准不同，不能写死。**

### 动手改（必做）

1. 给 `check_cps` 写测试：造一条"10 个字、500 毫秒"的字幕，应该报 too_fast
2. 加一条新规则 `check_duplicate`：两条字幕文本完全一样，报重复
3. 跑一下 `bad.srt`，看报出了几个问题，**逐个判断"它报得对吗"**

## Day 19 · 主项目：生成报告

### 亲手敲 `subtitle_qc/report.py`

```python
# report.py
# 作用：把问题列表变成一份能发给客户的 Markdown 报告

from datetime import datetime


def build_report(path, items, problems):
    now = datetime.now().strftime("%Y-%m-%d %H:%M")

    high = [p for p in problems if p["level"] == "high"]
    medium = [p for p in problems if p["level"] == "medium"]

    lines = []
    lines.append("# 字幕质检报告")
    lines.append("")
    lines.append("- 文件：%s" % path)
    lines.append("- 生成时间：%s" % now)
    lines.append("- 条目数：%d" % len(items))
    lines.append("")
    lines.append("## 结论")
    lines.append("")
    if not problems:
        lines.append("未发现问题。")
    else:
        lines.append("发现 **%d** 个问题，其中 **%d** 个必须修改。" % (len(problems), len(high)))
    lines.append("")
    lines.append("## 问题清单")
    lines.append("")
    lines.append("| 严重度 | 条目 | 类型 | 说明 |")
    lines.append("|---|---|---|---|")
    for p in problems:
        lines.append("| %s | %s | %s | %s |" % (p["level"], p["index"], p["type"], p["detail"]))
    lines.append("")
    return "\n".join(lines)
```

新建 `main.py`：

```python
# main.py
# 用法：python3 main.py samples/bad.srt

import sys

from subtitle_qc.parser import parse_srt
from subtitle_qc.rules import run_all
from subtitle_qc.report import build_report


def main():
    if len(sys.argv) < 2:
        print("用法：python3 main.py <srt 文件>")
        return

    path = sys.argv[1]
    items = parse_srt(path)
    problems = run_all(items)

    report = build_report(path, items, problems)
    out_path = path.replace(".srt", "_report.md")
    with open(out_path, "w", encoding="utf-8") as f:
        f.write(report)

    print("报告已生成：", out_path)


if __name__ == "__main__":
    main()
```

运行：

```bash
python3 main.py samples/bad.srt
cat samples/bad_report.md
```
