## Day 1 · 读文件，数行数

## Day 2 · 变量、列表、循环

### 学一个概念：循环 = 对每一个元素做同一件事

昨天的 `lines` 是一个列表。今天要对**列表里的每一行**做判断。

### 目标

数出：总行数、空行数、非空行数。

### 亲手敲

新建 `count2.py`：

```python
# count2.py
# 作用：统计文件的总行数、空行数、非空行数

file = open("sample.txt", "r", encoding="utf-8")
lines = file.readlines()
file.close()

total = len(lines)
empty = 0

for line in lines:
    # line 是字符串，strip() 去掉首尾空白（包括换行符）
    if line.strip() == "":
        empty = empty + 1

not_empty = total - empty

print("总行数：", total)
print("空行数：", empty)
print("非空行数：", not_empty)
```

运行：

```bash
python3 count2.py
```

**你应该看到**：
```
总行数： 5
空行数： 1
非空行数： 4
```

### 三个必须理解的点

**1. `for line in lines:` 在干什么**
把 `lines` 里的每一个元素，轮流赋值给 `line`，然后执行下面的代码。

**2. `line.strip()` 为什么必须有**
文件里的空行，读出来是 `"\n"`，不是 `""`。
`"\n".strip()` 才等于 `""`。**不加 strip，空行永远数不出来。**

**3. `empty = empty + 1` 为什么能累加**
先算右边（原来的 empty + 1），再赋给左边。
等价写法：`empty += 1`。

### 动手改（必做）

1. 把 `empty = empty + 1` 改成 `empty += 1`，确认结果一样
2. 加一行代码，数出**包含"行"字的行数**
3. 加一行，数出**最长的那一行有多少个字**

> 第 3 个有点难。提示：用一个变量 `max_len = 0`，循环里比较 `len(line)`。

## Day 3 · 字典、排序

### 学一个概念：字典 = 给每个东西记一个数

列表是"一排东西"，字典是"一个东西对应一个值"。
统计词频、统计次数，全靠字典。

### 目标

数出文件里**每个词出现了几次**，把出现最多的 3 个词列出来。

### 亲手敲

新建 `words.py`：

```python
# words.py
# 作用：统计词频，输出出现最多的 3 个词

file = open("sample.txt", "r", encoding="utf-8")
text = file.read()      # 注意：这次用 read()，不是 readlines()
file.close()

# 把文本按空白切成一个个词
words = text.split()

counts = {}
for w in words:
    if w in counts:
        counts[w] += 1
    else:
        counts[w] = 1

# 按次数从大到小排序
sorted_words = sorted(counts.items(), key=lambda x: x[1], reverse=True)

for w, c in sorted_words[:3]:
    print(w, c)
```

运行：

```bash
python3 words.py
```

**你应该看到**（大概）：
```
第一行 1
第二行 1
第四行是空的上面 1
```

> 因为你的测试文件里每个词只出现一次，所以排序后顺序可能不同。**这没关系，先跑通。**
> 想看到有意义的词频，可以让 `sample.txt` 里有重复的词。

### 三个必须理解的点

**1. `read()` 和 `readlines()` 的区别**

| 方法 | 返回 | 适合 |
|---|---|---|
| `read()` | 一整个字符串 | 要按词切分、要搜关键词 |
| `readlines()` | 列表，每行一个元素 | 要按行处理 |

**2. `counts[w] += 1` 的逻辑**
字典里如果没有这个键，直接 `+= 1` 会报错 `KeyError`。
所以要先判断 `if w in counts`。

**3. `sorted(..., key=lambda x: x[1], reverse=True)` 是什么**

- `counts.items()` 把字典变成 `[("词", 次数), ...]` 这样的列表
- `key=lambda x: x[1]` 意思是"按每个元素的第 2 个值（次数）排"
- `reverse=True` 从大到小
- `[:3]` 取前 3 个

> `lambda` 你现在不用深究，记住"它是在告诉 sorted 按哪一列排"就行。

### 动手改（必做）

1. 在 `sample.txt` 里加几行，让某个词出现 3 次，看排序变化
2. 把 `[:3]` 改成 `[:10]`，看输出几个
3. 加一行，输出**总共有多少个不同的词**（提示：`len(counts)`）

- [ ] 能说清 `read()` 和 `readlines()` 的区别
- [ ] 能说清 `sorted` 里那个 `key` 在干什么（用大白话）

## Day 4 · 函数、参数

### 学一个概念：函数 = 给一段代码起个名字

昨天写的代码，如果你想对另一个文件再统计一次，得复制一遍。
函数就是解决这个的：**把"做一件事"打包，起个名字，随时调用。**

### 目标

把前面的统计逻辑，拆成 2 个函数：`读文件` 和 `统计`。

### 亲手敲

新建 `count_func.py`：

```python
# count_func.py
# 作用：把"读文件"和"统计"拆成两个函数


def read_file(path):
    """读一个文件，返回所有行（列表）。"""
    with open(path, "r", encoding="utf-8") as f:
        return f.readlines()


def analyze(lines):
    """统计总行数、空行数、最长行的字数，返回一个字典。"""
    total = len(lines)
    empty = 0
    max_len = 0

    for line in lines:
        if line.strip() == "":
            empty += 1
        if len(line.strip()) > max_len:
            max_len = len(line.strip())

    return {
        "total": total,
        "empty": empty,
        "max_len": max_len,
    }


if __name__ == "__main__":
    lines = read_file("sample.txt")
    result = analyze(lines)
    print("总行数：", result["total"])
    print("空行数：", result["empty"])
    print("最长行字数：", result["max_len"])
```

运行：

```bash
python3 count_func.py
```

**你应该看到**：
```
总行数： 5
空行数： 1
最长行字数： 8
```

### 四个必须理解的点

**1. `def` 是定义函数**
`def read_file(path):` 意思是"定义一个叫 read_file 的函数，它需要一个东西，我们叫它 path"。

**2. `return` 是把结果交出去**
不写 return，函数做完就完了，结果丢了。

**3. `with open(...) as f:` 比 `open()` + `close()` 好**
它会**自动关闭文件**，哪怕中间出错。这是标准写法，以后都这么写。

**4. `if __name__ == "__main__":` 是什么**
意思是"只有直接运行这个文件时，才执行下面的代码"。
如果你以后在别的文件里 `import` 它，下面的代码不会自动跑。
**新手先记住：把"测试用的代码"放这个下面。**

2. 给 `analyze` 加一个返回值：`"words": len(" ".join(lines).split())`
3. 故意调用 `read_file("不存在.txt")`，看报错，**先别修**——明天就是讲这个

## Day 5 · 错误处理

### 学一个概念：程序会出错，出错要"接住"

昨天你故意调用不存在的文件，程序直接崩了。
真实世界里的程序不能这样——**客户给的文件可能不存在、可能是空的、可能格式不对。**

### 目标

让程序遇到"文件不存在"时，说一句人话，而不是崩一堆英文。

### 亲手敲

新建 `count_safe.py`：

```python
# count_safe.py
# 作用：在 count_func 的基础上，加错误处理

import os


def read_file(path):
    """读文件；文件不存在时返回 None。"""
    if not os.path.exists(path):
        print("找不到这个文件：", path)
        return None

    try:
        with open(path, "r", encoding="utf-8") as f:
            return f.readlines()
    except OSError as e:
        print("读文件失败：", e)
        return None


def analyze(lines):
    """统计；如果没数据，返回 None。"""
    if not lines:
        print("文件是空的，没什么可统计")
        return None

    total = len(lines)
    empty = sum(1 for line in lines if line.strip() == "")
    max_len = max(len(line.strip()) for line in lines)

    return {"total": total, "empty": empty, "max_len": max_len}


def main():
    path = "sample.txt"
    lines = read_file(path)
    if lines is None:
        return
    result = analyze(lines)
    if result is None:
        return
    print("总行数：", result["total"])
    print("空行数：", result["empty"])
    print("最长行字数：", result["max_len"])


if __name__ == "__main__":
    main()
```

运行，然后**故意测试三种情况**：

```bash
python3 count_safe.py                        # 正常
mv sample.txt sample_bak.txt && python3 count_safe.py   # 文件不存在
mv sample_bak.txt sample.txt                 # 恢复
```

### 五个必须理解的点

**1. `try / except` 是什么**
把"可能出错的代码"放 `try` 里，出错了就跳到 `except`，**程序不崩**。

**2. `return None` 表示"没有结果"**
调用方必须检查 `if lines is None`。**这是新手最容易漏的一步**——函数返回 None，下面继续用，就崩了。

**3. `sum(1 for line in lines if ...)` 是什么**
一种简写：数一数"满足条件的行"有几个。等价于你 Day 2 的循环。

**4. `max(... for line in lines)` 是什么**
取最大值。注意：如果 `lines` 是空的，`max()` 会报错——所以我们前面先判断了 `if not lines`。

**5. `os.path.exists()` 和 `try/except` 为什么要两个都写**
`exists` 是"预防"，`try` 是"兜底"。真实世界两个都要：
- 文件存在，但没权限读 → `exists` 通过了，`open` 才报错 → 靠 `try` 接住

### 动手改（必做）

## Day 7 · 输出 Markdown 报告

### 学一个概念：程序的产出要"能给人看"

前面都是 `print` 到终端。真实交付里，你要产出**文件**——报告、表格、清单。

### 目标

把统计结果写成一份 `.md` 文件，格式像这样：

```markdown
# 文件分析报告

- 文件：sample.txt
- 生成时间：2026-11-10 15:30

## 统计

| 项目 | 数值 |
|---|---|
| 总行数 | 5 |
| 空行数 | 1 |
| 最长行字数 | 8 |
```

### 亲手敲

新建 `report.py`：

```python
# report.py
# 作用：分析文件，输出一份 Markdown 报告

import os
from datetime import datetime


def read_file(path):
    if not os.path.exists(path):
        return None
    try:
        with open(path, "r", encoding="utf-8") as f:
            return f.readlines()
    except OSError:
        return None


def analyze(lines):
    if not lines:
        return None
    total = len(lines)
    empty = sum(1 for line in lines if line.strip() == "")
    max_len = max(len(line.strip()) for line in lines)
    return {"total": total, "empty": empty, "max_len": max_len}


def build_report(path, result):
    now = datetime.now().strftime("%Y-%m-%d %H:%M")
    lines = [
        "# 文件分析报告",
        "",
        "- 文件：" + path,
        "- 生成时间：" + now,
        "",
        "## 统计",
        "",
        "| 项目 | 数值 |",
        "|---|---|",
        "| 总行数 | " + str(result["total"]) + " |",
        "| 空行数 | " + str(result["empty"]) + " |",
        "| 最长行字数 | " + str(result["max_len"]) + " |",
        "",
    ]
    return "\n".join(lines)


def main():
    path = "sample.txt"
    lines = read_file(path)
    if lines is None:
        print("读不到文件，退出")
        return
    result = analyze(lines)
    if result is None:
        print("文件是空的，退出")
        return

    report = build_report(path, result)
    with open("report.md", "w", encoding="utf-8") as f:
        f.write(report)

    print("报告已生成：report.md")


if __name__ == "__main__":
    main()
```

运行：

```bash
python3 report.py && cat report.md
```

### 三个必须理解的点

**1. `"w"` 模式 = 写入**
`open("report.md", "w")` 会**创建或覆盖**文件。注意：**会覆盖！**

**2. `"\n".join(lines)` 是什么**
把一个字符串列表，用换行符连成一个大字符串。

**3. 为什么要 `str(...)`**
因为 `+` 只能拼字符串，数字要先转成字符串，否则报 `TypeError`。

### 动手改（必做）

1. 在报告里加一行"不同词的数量"
2. 把输出文件名改成带日期的：`report_2026-11-10.md`（提示：`datetime.now().strftime("%Y%m%d")`）
3. 让程序支持"传参"：`python3 report.py sample.txt`（提示：`import sys; sys.argv[1]`）
