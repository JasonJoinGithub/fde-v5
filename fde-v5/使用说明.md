## 怎么打开（30 秒）—— v5 改了，必读

### 方法一：双击「打开学习台.command」（推荐，唯一能存住进度的方法）

在访达里进到 `FDE学习App` 文件夹，**双击 `打开学习台.command`**。它会先起一个本地服务（`http://127.0.0.1:8000`），再用浏览器打开学习台。

如果 macOS 提示"无法打开，因为无法验证开发者"：
**右键点它 → 选「打开」→ 再点「打开」**。只需要做一次。

终端窗口要一直开着，关掉它服务就停了。按 `Ctrl+C` 可以主动停掉。

### 方法二：直接双击 HTML（不推荐，会丢进度）

双击 `FDE学习App.html` 也能打开页面，但**进度存不住**：Safari 在这种打开方式下不可靠，Chrome 则按文件路径给每个副本各存一份——打开 v4 的副本和 v5 的副本，进度各算各的，等于每次从零开始。这就是你以前每次打开都重新开始的原因。

实在要用这个办法，每次学完必须点「导出进度文件」备份，下次打开先点「导入进度文件」。

### 方法三：终端手动启动

```bash
cd ~/Documents/Deepseek\ Harness/FDE学习App
./start.sh
```

## 进度存在哪，怎么备份

进度存在浏览器里（localStorage，key 仍是 `fde_app_v1`，和 v4 一样，所以同一个来源打开时旧进度能直接迁移过来）。

- **不会上传**，不会联网
- **用本地服务打开**（方法一）：进度跨版本留住，v4 学过的打勾不会丢
- **直接双击 HTML 打开**：存不住，或每个副本各存一份
- **换浏览器或清缓存会丢**：所以要定期备份

备份办法（首页和「我的进度」里都有大按钮，页脚也有）：

- **导出进度文件**：下载一个 `fde-progress-日期.json`，存在你电脑上
- **导入进度文件**：打开以前导出的 `.json`，打过的勾、答过的题都会回来

建议：每周学完导一份，存在 `~/fde-code/notes/` 旁边。

## 出问题怎么办

| 现象 | 解决 |
|---|---|
| 双击 .command 没反应 | 右键 → 打开 → 打开 |
| 页面顶部出现红色警告"存不住进度" | 你是直接双击 HTML 打开的，关掉，改用「打开学习台.command」 |
| 进度没了 | 两种可能：清过缓存，或直接双击 HTML 打开了另一个副本。以后用方法一打开，并定期点「导出进度」；有备份就点「导入进度」恢复 |
| 页面空白 | 换 Chrome 或 Safari 再试；或检查终端里的服务还在不在 |
| 搜索不到词 | 只搜概念名里的字，比如「评测」而不是「怎么评测」 |
